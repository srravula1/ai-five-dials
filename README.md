# Five Dials on the Machine Mind - Visualizations

A suite of interactive visualizations for your essay series on AI cognitive architecture.

## Files Included

### 1. **five-dials-dashboard.html** - Interactive Dashboard
The centerpiece visualization featuring:
- Five adjustable sliders for each cognitive dial
- Real-time configuration analysis
- Preset buttons for different AI system types (Early AI, Modern LLM, Autonomous Agents, etc.)
- Dark, technical aesthetic with glowing accents
- Perfect for: Substack article embedding, interactive exploration

**Best for:** Main essay anchor, letting readers experiment with different AI configurations

---

### 2. **ai-evolution-timeline.html** - Historical Timeline
A vertical timeline showing:
- How each dial evolved from 1950s to 2025
- Five distinct eras with specific dial levels
- Key innovations and developments for each period
- Clean, editorial design
- Perfect for: Historical context, showing progression over time

**Best for:** "How we got here" section, explaining AI development trajectory

---

### 3. **ai-systems-comparison.html** - Radar Charts
Compare different AI systems side-by-side:
- Radar/spider charts for visual comparison
- Four system types: Early AI, Modern LLM, Recommendation Systems, Autonomous Agents
- Filterable views
- Detailed metrics with insights
- Dark, modern aesthetic
- Perfect for: Comparing different AI architectures

**Best for:** "Different systems, different profiles" discussion, stakeholder presentations

---

### 4. **five-dials-infographic.html** - Social Media Graphic
A shareable static infographic (1200x1200px):
- Clean, professional design
- All five dials with icons
- Current 2025 baseline levels
- Optimized for LinkedIn/Twitter sharing
- Gradient background, high visual impact
- Perfect for: Social media, presentation slides, promotional material

**Best for:** LinkedIn posts, Twitter threads, newsletter headers

---

## Usage Guide

### For Substack
1. **Primary visualization:** Use `five-dials-dashboard.html` embedded in your main essay
2. **Supporting content:** Link to `ai-evolution-timeline.html` for readers who want historical depth
3. **Comparison section:** Embed `ai-systems-comparison.html` when discussing different AI types

### For LinkedIn
1. Take a screenshot of `five-dials-infographic.html` (or use browser dev tools to export at 1200x1200)
2. Post as carousel with each dial as a separate slide
3. Include link to full dashboard in comments

### For Presentations
- Use dashboard for live demos and Q&A
- Timeline for background/context slides
- Comparison charts for stakeholder discussions
- Infographic for executive summaries

### For Email Newsletters
- Link to hosted versions of interactive visualizations
- Include static screenshot of infographic as header image
